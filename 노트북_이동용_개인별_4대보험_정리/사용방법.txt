[개인별 4대보험 정리 - 노트북 이동용]

1. ZIP 파일을 노트북으로 복사합니다.
2. ZIP 파일을 마우스 오른쪽 버튼으로 눌러 "압축 풀기"를 선택합니다.
3. 개인별_4대보험_정리.html 파일을 더블클릭합니다.
4. 귀속 연월을 확인하고 보험 파일 5~6개를 선택합니다.
   - 필수: 건강보험 CSV, 고용보험 XLS·CSV, 산재보험 XLS·CSV
   - 선택: 국민연금 CSV (국민연금 내역이 없는 달에는 생략 가능)
5. 통합내역을 확인한 후 "엑셀로 저장"을 누릅니다.

[지니행정도구에 넣는 방법]

- 지니행정도구가 HTML 파일을 등록하는 방식이면 개인별_4대보험_정리.html 파일 하나만 등록합니다.
- 메뉴 이름은 "개인별 4대보험 정리"로 지정합니다.
- 파일 위치를 옮기더라도 HTML 파일 하나만 함께 이동하면 됩니다.

[포함된 기능]

- 보험 파일 다운로드 안내
- 원본 PDF 설명서 보기 및 저장
- 건강·국민연금·고용·산재 자료 자동 분류 (국민연금은 선택)
- 개인별 보험료 통합 및 검증
- 합계 표시 및 엑셀 저장

[개인정보 안내]

- 선택한 보험 파일은 사용 중인 브라우저 안에서만 처리됩니다.
- 파일 내용은 외부 서버로 전송하거나 저장하지 않습니다.
- 광고, 방문자 분석, 외부 스크립트를 사용하지 않습니다.

※ 인터넷 연결이나 별도 프로그램 설치가 필요하지 않습니다.
