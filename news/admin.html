새 소식을 확인하고, 직접 글을 올리거나 수집할 사이트를 관리하세요.

← 소식 게시판

관리자 연결

운영 환경에 설정한 관리자 키를 입력하세요. 브라우저에 저장하지 않으며, 새로고침하면 다시 입력합니다.

게시글 관리

0개 선택

체크한 글만 한 번에 처리합니다. ‘더 보기’로 불러온 글도 선택할 수 있어요.

원문 변경 확인

게시한 글이나 직접 수정한 글은 자동으로 덮어쓰지 않아요. 변경된 내용을 확인한 후 반영하세요.

수집 사이트

매일 오전 7시(한국 시간)에 확인합니다. 초기에는 확인 대기로 가져옵니다. 페이지형 목록은 다음 페이지까지 순서대로 확인합니다. 상세 글이 한 번에 30건을 넘거나 페이지·시간 한도에 걸리면 일부 처리 또는 미완료 사유가 표시되며 다음 실행에서 남은 항목을 다시 확인합니다. 사이트별 마지막 성공 시각과 오류도 확인해 주세요.

소식 작성

원문에서 확인하기 ↗

강좌·강연·세미나·체험 프로그램은 ‘평생·문화교육’으로 묶습니다. 분류는 위에서 바꿀 수 있어요.

직접 촬영했거나 이용 허락을 받은 사진을 올려주세요. 사진은 자동으로 줄여 저장합니다.

수집 사이트 설정

새 주소를 등록하면 목록에 보관됩니다. 처음 보는 사이트는 제목·날짜·장소 위치를 맞추는 작업이 필요합니다. 주소만으로 모든 사이트를 자동 해석하지는 않습니다.

수집 항목 설정 · 개발자용

필수: links(목록의 상세 링크), title, date, venue. 선택: time, price, images. 날짜에 연·월·일이 표시된 요소를 지정하세요.
